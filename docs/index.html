Die Timebutler-Stempeluhr,
immer im Blick.

Native macOS-App für die Stempeluhr von Timebutler: Start, Pause und Stopp aus einem schwebenden Widget, die laufende Arbeitszeit in der Menüleiste, kein Browser-Tab mehr.

Download für macOS Neueste Version Quellcode auf GitHub

macOS 26 (Tahoe) oder neuer · Apple Silicon und Intel · signiert und von Apple notarisiert

Braucht ein Timebutler-Konto mit aktivierter Zeiterfassung.
